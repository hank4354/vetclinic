# VetClinic

Консольное приложение для учёта работы ветеринарной клиники. Курсовой проект по объектно-ориентированному программированию в Московском Политехе. Автор — Хэнк Калашян.

В приложении можно:

- Вести карточки животных и записи о сотрудниках, искать и фильтровать записи.
- Регистрировать и редактировать приёмы, просматривать медицинские карты животных и историю работы ветеринаров.
- Рассчитывать стоимость услуг и просматривать чеки.

Проект написан на C# под .NET 9. Наследование используется в моделях животных и сотрудников: у животных есть отдельные классы для собак, кошек и птиц, у сотрудников — для ветеринаров и администраторов.

## Запуск

Установите .NET 9 SDK и выполните из корня репозитория:

```sh
dotnet run --project VetClinic.csproj
```

При первом запуске журнал пуст. При выходе через пункт меню `0` приложение сохраняет данные в локальный файл `clinic_data.json`.
